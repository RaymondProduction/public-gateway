Підключити пристрій

1–32 символи: a-z, 0-9, _ або -. Та сама назва повторно повертає ту саму VPN-адресу.

Як підключитися

Linux: збережи файл як /etc/wireguard/pgw0.conf з правами 600, далі sudo systemctl enable --now wg-quick@pgw0.

Windows / macOS: у застосунку WireGuard «Import tunnel(s) from file» і вибери завантажений файл.

Android / iOS: у застосунку WireGuard «+» → «Scan from QR code» і відскануй код вище.

Перевірка: ping . Програма на пристрої має слухати свою VPN-адресу, а не лише 127.0.0.1.

Додати або перемкнути маршрут
Для домену потрібен A-запис на адресу VPS; сертифікат Caddy отримає сам. Той самий домен з іншим пристроєм перемикає маршрут. Резервний пристрій має запускати ту саму програму на тому самому порту: коли основний недоступний, трафік іде на резервний і повертається сам, щойно основний відповідає.
